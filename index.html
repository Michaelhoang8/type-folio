Language reference

        
      

      

        

          

            
Expressions

            
let name = expression in expression
fun name -> expression
if condition then yes else no
function argument
(first, second)
fst pair  /  snd pair

            

              Integers, booleans, names, parentheses, +, −, *, and integer-only ==. Application
              binds tighter than multiplication, then addition/subtraction, then equality. Use
              parentheses around negative function arguments. Comments start with --.
            

          

          

            
Supported model

            

              Nonrecursive let-polymorphism, monomorphic lambda parameters, and an occurs check. No
              mutation, recursion, strings, lists, type classes, subtyping, or evaluation. Type
              checking does not execute the program.
            

            

              12,000 UTF-16 code units; 1,500 tokens; 500 expression nodes; bounded parser/inference
              nesting and unification work. Large displayed types are abbreviated with …, while
              analysis uses the complete type graph.
            

            

              Save a folio before refreshing. Imported line endings remain exact until you edit the
              source, when the browser may normalize them.
